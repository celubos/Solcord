# Solcord 2.0.4

This release finishes the polish started in 2.0.3: a consistent Control Center, a tidier Setup, and one shared home for all encrypted local storage. Strict Privacy, Message History and Fake Deafen behave exactly as before.

## Install or update

Download **SolcordInstaller.exe**, open it, and choose the recommended button: **Install Solcord**, **Update Solcord**, or **Turn Solcord back on**. Settings, plugins, themes and private stores are kept. The [quick start](../QUICK_START.md) has the three steps with pictures.

The Windows installer is unsigned, so SmartScreen may ask you to confirm. Use only the files attached to this release; `SHA256SUMS.txt` lets you check the download.

## Control Center

- **One switch layout.** Every switch sits at the end of its row, and all switch rows share one width. This covers settings lists, Fake Deafen, privacy status, Message History, the Performance HUD, option grids, Layout Collapse, and the setup wizard.
- **Readable setup steps.** Step names stay visible at every width; in narrow windows the number sits above the name, and the step rail lines up with the progress bar.
- **One title in the settings dialog.** The dialog shows the Solcord mark, name and Close once, and Back and Continue stay reachable in short windows.
- **Clearer links.** Solcord Dark links are teal (at least 9.4:1 contrast) instead of a coral that looked like a warning.

## Setup

- **Check files** and **Backups** sit in the **More options** list with Repair, Roll back and Uninstall, so every action lines up.
- **Ready to install** lists what installing does: how long it takes, what's kept, and how to undo it.
- Uninstalling from **Solcord Setup** removes its Start menu and Settings entries right away and deletes its own copy after the window closes. Before, the copy could be left behind.
- `SolcordInstaller.exe --update --channel Stable` also refreshes **Solcord Setup**, the Settings → Apps entry and the Start menu shortcut.
- If a newer Solcord is installed, Setup always says **Newer version installed** and changes nothing, even when the newer install record has fields this version doesn't know.

## Under the hood

People and Spaces, Audience Guard, Local Identity Notes, Friend Watch and translation credentials now share one encrypted-storage module. Files, folder permissions, error messages and crash recovery are unchanged; a side-by-side run of the old and new code through 80 recovery scenarios matched in every case. Duplicated code in the app's main process dropped from 1.84% to 0.97%.

## macOS preview

The Apple Silicon and Intel command-line previews are rebuilt from this source. They are ad-hoc signed and not notarized; real Mac Discord startup, microphone, keychain and update behavior are still unverified. Read the [Mac preview guide](../MACOS.md) before using them.
