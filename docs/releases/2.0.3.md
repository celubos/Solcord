# Solcord 2.0.3

This release keeps Solcord switched on when Discord updates itself and makes Setup much easier to understand and find again. Strict Privacy, Message History and the accepted Fake Deafen behavior are unchanged.

## Install or update

On Windows x64, download **SolcordInstaller.exe** and **SHA256SUMS.txt**, verify the checksum, save drafts and leave calls, then open Setup and choose its recommended action. If Solcord stopped working after a Discord update, Setup says **Solcord is off** and the button reads **Turn Solcord back on**. Existing settings, plugins, themes and private stores are preserved.

After this install you do not need the download again: open **Solcord Setup** from the Start menu, or **Settings → Apps → Installed apps → Solcord**.

The Windows installer is unsigned. Use only the packages and checksums attached to this repository's release; do not disable Windows security.

## Discord updates no longer switch Solcord off

Discord now downloads updates in the background, installs them in a new folder while it is still running, and deletes the old folder later. Solcord 2.0.2 only reattached itself when Discord quit normally, so a background update could leave the new Discord version without Solcord.

- While Discord runs, Solcord checks once a minute for a newly installed Discord version and attaches to it as soon as its files have stopped changing for a minute. It still tries again when Discord quits, with short retries if a file is briefly locked.
- If Discord updated while Solcord was not running, the Start menu **Solcord** entry turns Solcord back on and then opens Discord. It only does this when Discord is closed; it never closes Discord for you. Anything that needs a decision opens Setup instead.
- A newer Solcord now reattaches cleanly even when Discord already deleted the version Solcord was recorded against.
- Update results are written to a small local log (`BetterDiscord\data\updater.log`) containing only result codes and times, never paths or message content.

## A clearer Setup

- Each state says what is going on in plain words: **Solcord is on**, **Solcord is off**, **Update available**, **Needs repair**, **Unfinished change**, **Ready to install**.
- Opening an older installer no longer reports "The current Solcord install receipt failed validation". It says **Newer version installed**, names the installed version, and changes nothing.
- Setup keeps a current copy of itself at `%LOCALAPPDATA%\Solcord\Setup\SolcordSetup.exe`, adds **Solcord Setup** to the Start menu, and registers **Solcord** in Settings → Apps. Uninstall from either place removes those entries again; plugins, themes, settings and backups stay.
- The **Solcord** Start menu entry now uses Discord's current launcher (the same one Discord's own shortcut uses) instead of Squirrel's older `Update.exe`, and a Solcord shortcut left without its record by an interrupted older Setup is repaired instead of blocking the shortcut forever.
- Clearer labels: **Open Discord**, **Check files**, **Open backups folder**, **More options**.

## Code quality

Duplicate path-safety, atomic-write and Discord channel code in the installer now lives in one shared place, so a fix applies everywhere at once.

## macOS preview

The Apple Silicon and Intel command-line previews are rebuilt from this source. They are ad-hoc signed and not notarized; real Mac Discord startup, microphone, keychain and update acceptance remain unverified. Read the [Mac preview guide](../MACOS.md) before using them. No quarantine removal or Gatekeeper bypass is provided.

## Verification scope

The release workflow requires source tests, lint, types, documentation/inventory checks, Windows recovery and embedded installer tests, and both native Mac packaging jobs. Package manifests and `release-package.json` bind the downloads to the source commit. `RELEASE-SHA256SUMS.txt` covers all attachments except itself.

| Controlled check | Result |
| --- | --- |
| Discord background update | A staged version is left alone while it is still changing or incomplete, then attached once stable; the running-client watch attaches without a quit; the quit hook retries a locked archive and never throws |
| Windows installer recovery | All 2.0.2 recovery cases, plus: a background-updated Discord that removed the recorded version is reattached by a newer package and uninstalls to vanilla; newer and older receipts are named without strict validation; launcher target selection, orphaned-shortcut adoption, and foreign shortcuts left untouched |
| Embedded installer self-test | Plain-language states (Solcord is off, newer installed, unfinished change) and the Setup copy, Start menu entry and Settings → Apps entry, using disposable folders and a private registry key that is removed afterwards |

The renderer, settings, voice and backend measurements did not change because none of their measured source files changed; the [machine-readable measurements and source hashes](2.0.3-performance.json) (also attached as **solcord-performance.json**) record the commit they ran on. The release assembler rejects changed measured source files.

Not verified by this release's automated checks: a real Discord background update on a signed-in installation, the Start menu healing launch on the owner's PC, and any real Mac startup, microphone, keychain or update behavior. Mac packages remain ad-hoc signed, non-notarized command-line previews.
